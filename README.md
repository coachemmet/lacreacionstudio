# La Creación Studio — GitHub Pages

Sitio estático actualizado con materiales autorizados proporcionados por el estudio.

## Publicación

Sube el contenido de esta carpeta (no la carpeta contenedora) a la raíz de tu repositorio de GitHub. En Settings → Pages elige Deploy from a branch, `main`, `/ (root)`.

## Páginas

- `index.html` — página principal.
- `futbol-fest.html` — sección ampliada del evento.
- `gaming-fest.html` — concepto del festival.
- `assets/` — imágenes optimizadas exportadas de los PDF suministrados.

## Ajustes antes de publicar

- Verifica fechas, cupos, equipos y condiciones de patrocinio del Fútbol Fest.
- En `index.html`, configura `CONFIG.whatsapp` si deseas activar el botón de WhatsApp.
- Confirma que `eli@thecreation.studio` y `@thecreation_studio` son los contactos públicos deseados.
- Sustituye las imágenes extraídas de presentaciones por archivos originales a mayor calidad cuando estén disponibles.
